# RIR Tours and Travels

A modern, high-performance, and responsive web application for **RIR Tours and Travels** — premier tour operator, taxi service, and travel provider in Kodaikanal, Tamil Nadu.

## Features

- **Tour Packages**: Curated holiday packages including Honeymoon, Family, Group, and Adventure tours in Kodaikanal.
- **Cab & Taxi Services**: Real-time cab booking, local sightseeing transfers, outstation cabs, and one-way drops (Madurai, Coimbatore, Dindigul, Trichy).
- **Direct Concierge & Booking**: Quick WhatsApp and direct phone call booking integration.
- **Dedicated SEO Landing Pages**: Targeted local landing pages for high search visibility:
  - Kodaikanal Tour Packages
  - Kodaikanal Taxi Service
  - Kodaikanal One-Way Drop
  - Madurai to Kodaikanal Taxi
  - Kodaikanal Sightseeing
  - Kodaikanal Tour Operator
- **Fast & Responsive**: Mobile-first architecture built with React, Vite, and Tailwind CSS.
- **Search Engine Optimization**: Structured JSON-LD schema (TravelAgency, BreadcrumbList), Open Graph tags, canonical URLs, and XML sitemaps.

## Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router v7
- **Styling**: Tailwind CSS v4 & custom responsive design system
- **Linter**: Oxlint
- **Icons**: Inline SVG icons optimized for zero-bundle overhead

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Thirukarthikj/sample.git

# Navigate to project directory
cd sample

# Install dependencies
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

### Linting

Run Oxlint to check code quality:

```bash
npm run lint
```
